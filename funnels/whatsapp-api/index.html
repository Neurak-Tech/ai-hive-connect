For the developer setting it up

Here's what the code looks like

Sending is one request. Add a unique key to each message, and if your server sends it again by accident, the customer still gets it once.

Receiving updates is just as simple. We send each update to your server with a signature, so you can check it's really from us. Reply "OK" within 5 seconds, then handle it however you like.

Not sure it's working? Send yourself a test update and check the log of everything we've sent you.

import crypto from "node:crypto";

app.post("/hooks/whatsapp",
  express.raw({ type: "application/json" }),
  (req, res) => {
    const sig = req.get("X-Hive-Signature") || "";
    const expected = "sha256=" + crypto
      .createHmac("sha256", process.env.HIVE_WEBHOOK_SECRET)
      .update(req.body).digest("hex");

    if (sig.length !== expected.length ||
        !crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected)))
      return res.sendStatus(401);

    res.sendStatus(200);          // ack inside 5 s
    queue.add(req.get("X-Hive-Event"), JSON.parse(req.body));
  });
import hmac, hashlib, os
from flask import Flask, request, abort

app = Flask(__name__)
SECRET = os.environ["HIVE_WEBHOOK_SECRET"].encode()

@app.post("/hooks/whatsapp")
def hook():
    raw = request.get_data()
    expected = "sha256=" + hmac.new(SECRET, raw, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(request.headers.get("X-Hive-Signature", ""), expected):
        abort(401)
    enqueue(request.headers["X-Hive-Event"], request.get_json())
    return "", 200   # ack inside 5 s

Is this the official WhatsApp Business API?

Yes. AI Hive is an approved Meta Tech Provider, and your number runs on Meta's official WhatsApp platform. You can use a new number, or keep your current WhatsApp Business app number and add automation on top.

How does my app connect?

You get a secret API key. Your app includes it with every request, and each key can be limited to what it needs, like only sending messages.

What if my server sends the same message twice?

Give each message a unique ID when you send it. If the same ID comes in again, we won't send it a second time.

How do I know if a bulk send failed for some numbers?

You can send one message to up to 50 people in one go. The response lists every number, and any that failed shows the reason next to it.

Can I reuse the code I wrote for Meta's WhatsApp API?

Yes. Send the same messages to our address instead of Meta's. We add the access key for you and check your wallet balance.
